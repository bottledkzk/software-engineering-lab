## 1. 基线声明

1. **沿用实验一选题**：轻量级益智消除类网页游戏《星尘消除》，未换题、未重新提出选题。
2. **沿用实验一需求编号**：本文档与《01_设计文档》引用的 `FR-01~FR-20`、`NFR-01a~NFR-08`、`AC-01~AC-37`、`AS-01~AS-10` 全部与实验一 v1.2 文档**同名同义**，未重新编号、未改变语义。
3. **基线版本**：实验一文档在提交后经历两轮修订（v1.0 → v1.1 → v1.2），本设计以 **v1.2** 为准；两轮修订的逐项说明见《03_需求变更说明》。

## 3. 非功能需求基线（NFR-01a ~ NFR-08，共 22 条）

| 分类 | 编号 | 一句话指标 | 设计应对 |
| --- | --- | --- | --- |
| 性能 | NFR-01a | 首屏可交互 ≤2 s（目标）/≤3 s（上限）；4G + 中端 Android；按 6 Mbps 折算关键资源 ≤1.2 MB | NFD-01 |
| 性能 | NFR-01b | 帧率 ≥50 fps（目标 60） | NFD-02、UI-04 |
| 性能 | NFR-01c | 交换输入到动画启动 ≤100 ms | NFD-03 |
| 性能 | NFR-01d | 内存峰值 ≤150 MB；1000 次操作增量 ≤50 MB | NFD-04 |
| 性能 | NFR-01e | 静态资源 ≤3 MB（gzip ≤1.5 MB）；首屏关键 gzip ≤1.2 MB；音频 ≤1 MB 且懒加载 | NFD-05 |
| 性能 | NFR-01f | 首次加载后可离线运行；非关键资源首次交互后请求 | NFD-06、MOD-09 |
| 兼容 | NFR-02a | Chrome/Edge/Firefox 近两大版本、Safari/iOS Safari ≥15、Android Chrome ≥100；不支持 IE | NFD-07、ERR-05~07 |
| 兼容 | NFR-02b | ≥360×640 自适应，棋盘不裁切 | NFD-07、UI-08 |
| 兼容 | NFR-02c | 无插件依赖（纯 HTML5） | NFD-07、DEC-02 |
| 易用 | NFR-03a | 无引导 5 min 内过第 1 关（5 人中 ≥4 人） | NFD-08、TEST-07 |
| 易用 | NFR-03b | 新手引导 ≤60 s，可跳过 | UI-05 |
| 易用 | NFR-03c | 按钮触控目标 ≥44×44 px | UI-08 |
| 易用 | NFR-03d | 界面全中文，无英文游戏术语 | UI-08 |
| 可靠 | NFR-04a | 存档写入成功率 100%（连续 200 次 0 失败）；失败必须提示 | NFD-09、ERR-02 |

| 可维护 | NFR-08 | 关卡配置驱动：新增 1 关不改代码 | NFD-13、DEC-04 |

## 6. 范围外清单（基线 §9.2，共 11 项）

在线排行榜/云存档/账号系统；广告/内购/体力值；好友对战与社交 SDK；纯合成玩法；障碍地形；计时/每日挑战/无尽模式；玩家关卡编辑器；多语言；原生 App/微信小游戏封装；排行榜防作弊；皮肤/主题装扮。

> 设计侧复述见《01_设计文档》§2.4：这些能力**不实现、不预留承诺**，但架构上保证不阻碍其未来接入（例如替换 MOD-05 的存储后端即可支持云存档）。
